### 3. Сценарии ручного тестирования UI

#### Сценарий 1: Переключение зон и выбор зданий друга
1. Открыть Task Planner (`/tasks`).
2. Выбрать аккаунт, установить действие `Применить баф`.
3. Нажать кнопку **«Зона друга»** -> Выбрать друга из списка.
4. Нажать **«Выбрать здания друга»**.
5. **Результат:** Загружаются и отображаются здания выбранного друга. В модальном окне отсутствуют лишние табы.

#### Сценарий 2: Закрытие модального окна
1. Открыть модальное окно выбора зданий.
2. Проверить варианты закрытия:
   - Клик по крестику `❌` в углу.
   - Клик по затемненной области вне окна (backdrop click).
   - Нажатие клавиши `ESC`.
3. **Результат:** Модальное окно корректно закрывается во всех случаях.

#### Сценарий 3: Сохранение времени задержки
1. Указать время задержки `30` секунд.
2. Добавить действие в серию.
3. **Результат:** Действие успешно добавляется в серию, а значение в поле ввода задержки остается равным `30` секунд (не сбрасывается к `5`).

#### Сценарий 4: Порядок задач (новые задачи вверху)
1. Создать новую задачу.
2. **Результат:** Новая задача мгновенно появляется на **первой позиции** вверху списка задач аккаунта.

#### Сценарий 5: Двухъязычное отображение ошибок (English / Русский)
1. Выполнить задачу, завершившуюся с кодом ошибки игрового сервера (например, код `550` или `25`).
2. Переключить язык интерфейса на **Русский** -> Текст ошибки: `Передано недопустимое значение`.
3. Переключить язык интерфейса на **English** -> Текст ошибки: `Invalid value provided`.
4. **Результат:** Сообщения об ошибках серверов динамически локализуются на выбранный язык.
