# Verification: Мультивыбор зданий и специалистов в Task Planner

## План верификации

### 1. Автоматическое тестирование (PHPUnit)
Запуск существующих и новых интеграционных тестов планировщика задач:
```bash
php artisan test --filter=ScheduledTaskTest
```

### 2. Сборка фронтенда (Vite / npm)
Проверка отсутствия ошибок синтаксиса Vue 3 / JS при компиляции:
```bash
npm run build
```

### 3. Ручные сценарии тестирования UI

#### Сценарий 1: Мультивыбор зданий своего острова
1. Открыть Task Planner (`/tasks`).
2. Выбрать аккаунт.
3. Выбрать тип действия `Применить баф` -> `Моя зона`.
4. Нажать `Выбрать здания`. Отметить 3 здания (например, Лесопилка, Ферма, Шахта).
5. Выбрать 1 баф (например, `Production Boost`).
6. Нажать `Добавить шаг`.
7. **Ожидаемый результат**: В списке `sequenceActions` появляется 3 отдельных шага, по одному на каждое выбранное здание.

#### Сценарий 2: Одновременный выбор зданий своего острова и друга
1. Выбрать тип действия `Применить баф`.
2. В модальном окне зданий выбрать 2 собственных здания и 2 здания друга.
3. Добавить шаг.
4. **Ожидаемый результат**: Создаются 4 независимых действия: 2 с `target_scope: 'self'` и 2 с `target_scope: 'friend'` (с указанием ID и имени друга).

#### Сценарий 3: Мультивыбор специалистов
1. Выбрать тип действия `Отправить геолога`.
2. Открыть модальное окно выбора специалистов. Отметить 3 геолога.
3. Выбрать целенаправленный поиск (например, `Медь`).
4. Нажать `Добавить шаг`.
5. **Ожидаемый результат**: Создается 3 отдельных действия отправки геолога.

#### Сценарий 4: Редактирование и удаление целей до создания
1. Отметить 5 зданий.
2. В блоке выбранных целей удалить 2 здания нажатием на крестик `✕`.
3. Нажать `Добавить шаг`.
4. **Ожидаемый результат**: В серию добавляется ровно 3 действия.
