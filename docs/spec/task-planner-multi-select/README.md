# SDD: Поддержка множественного выбора зданий и специалистов в Task Planner

- **Статус:** Draft для ревью
- **Версия пакета:** 1.0
- **Проект:** Laravel 10 / Vue 3 (TSO Manager)
- **Компонент:** Task Planner (`resources/js/views/Tasks.vue`)

## Назначение

Настоящий пакет SDD задает спецификацию и план реализации поддержки множественного выбора зданий и специалистов при формировании задач и серий действий в планировщике задач (**Task Planner**).

## Документы

1. [Requirements](requirements.md) — требования, цели, инварианты, сценарии и acceptance criteria.
2. [Design](design.md) — интерфейс пользователя, структура состояния Vue 3, алгоритм разворачивания множественных целей в атомарные действия.
3. [Implementation Plan](implementation-plan.md) — этапы разработки, файлы изменений и Definition of Done.
4. [Verification](verification.md) — стратегия тестирования и верификация результата.

## Ключевые решения

- **Мультивыбор на Frontend**: Пользователь может одновременно выбрать несколько собственных зданий, зданий друзей и/или нескольких специалистов в форме шага.
- **Атомарность действий (Backend compatibility)**: При добавлении шага множественные цели автоматически разворачиваются в единый список независимых действий (`sequenceActions`), сохраняя 100% совместимость с моделью исполнения и API backend.
- **Одинарные бафы**: Баф выбирается строго в единственном числе (один баф на выбранную группу зданий).
- **Интерфейс**: Включение чекбоксов, бейджей выбранных объектов, возможность удаления отдельных объектов из списка до добавления шага и групповые операции ("Выбрать все" / "Очистить").
