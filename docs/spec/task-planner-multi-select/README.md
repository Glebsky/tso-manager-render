# SDD: Поддержка множественного выбора зданий и специалистов в Task Planner

- **Статус:** Approved / Implemented
- **Версия пакета:** 1.1
- **Проект:** Laravel 10 / Vue 3 (TSO Manager)
- **Компонент:** Task Planner (`resources/js/views/Tasks.vue`, `ScheduledTaskController.php`, `GameErrorResolver.php`)

## Назначение

Настоящий пакет SDD задает спецификацию и документацию реализованной поддержки множественного выбора зданий и специалистов при формировании задач и серий действий в планировщике задач (**Task Planner**).

## Ключевые решения

- **Мультивыбор на Frontend**: Пользователь может одновременно выбрать несколько зданий (своего острова или острова выбранного друга) и/или нескольких специалистов при добавлении действия.
- **Интерфейс зон**: Форма содержит переключатель «Моя зона» / «Зона друга». При выборе зоны друга активируется выбор друга и загрузка его зданий. Модальное окно зданий избавлено от внутренних табов зон, поддерживает закрытие по кнопке (❌), клику на пустое место (оверлей) и клавише ESC.
- **Сохранение параметров задержки**: Время задержки (`stepDelay`) не сбрасывается к 5 секундам при добавлении действия и сохраняет введенное значение.
- **Сортировка задач**: Задачи в списке Scheduled Tasks всегда выводятся по убыванию ID (`id desc`), отображая новые задачи на самом верху.
- **Двухъязычный маппинг ошибок**: Ошибки игрового сервера декодируются через `GameErrorResolver` и выносятся в языковые файлы `lang/en/ui.php` (английский по умолчанию) и `lang/ru/ui.php` (русский), динамически переключая язык сообщений об ошибках в UI.
- **Атомарность действий (Backend compatibility)**: При добавлении действия множественные цели автоматически разворачиваются в независимые действия в массиве `sequenceActions`, сохраняя 100% совместимость с моделью исполнения backend.
