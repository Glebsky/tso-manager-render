# Implementation Plan: Мультивыбор зданий и специалистов в Task Planner

## Этапы разработки

### Этап 1: Обновление состояния и реактивных функций в `Tasks.vue`
1. Замена `selectedBuilding`, `selectedFriendBuilding` на `selectedBuildings` (массив целевых объектов).
2. Замена `selectedSpecialist` на `selectedSpecialists` (массив специалистов).
3. Сохранение одиночного `selectedBuff`.
4. Реализация хелперов переключения выбора, добавления и удаления элементов (`toggleBuildingSelection`, `removeSelectedBuilding`, `toggleSpecialistSelection`, `removeSelectedSpecialist`).

### Этап 2: Модификация модальных окон
1. **Модальное окно зданий**:
   - Поддержка вкладок "Мой город" и "Город друга".
   - Мультиселект с чекбоксами/подсветкой выбранных карточек.
   - Кнопка "Выбрать все" / "Очистить".
   - Фильтрация по категориям и поисковой строке для обоих источников.
2. **Модальное окно специалистов**:
   - Мультиселект с чекбоксами/подсветкой.
   - Поиск и фильтрация.
   - Кнопки массового выделения.

### Этап 3: Компонент отображения выбранных целей (Chips / Badges)
1. Встраивание панели выбранных целей в форму шага конструктора.
2. Отображение списков выбранных зданий (с иконкой, типом, grid, владельцем) и специалистов (с иконкой, именем, категорией).
3. Элементы индивидуального удаления `✕`.

### Этап 4: Разворачивание множественного выбора в действия (`addStepToSequence`)
1. Валидация наличия хотя бы одной цели при добавлении шага.
2. Цикл итерации по выбранным зданиям/специалистам с генерацией отдельного действия для каждого объекта в `sequenceActions`.
3. Очистка временных массивов выбора после добавления шагов.

### Этап 5: Сборка и верификация
1. Компиляция фронтенда через `npm run build`.
2. Проверка стиля `./vendor/bin/pint`.
3. Проверка кода `./vendor/bin/phpstan analyse`.
4. Запуск интеграционных PHPUnit-тестов `php artisan test`.
5. Проверка отсутствия регрессий в интерфейсе планировщика задач.

## Definition of Done
- [ ] Оформлены и закоммичены документы SDD в `docs/spec/task-planner-multi-select/`.
- [ ] Пользователь может выбрать несколько зданий своей зоны и зоны друга одновременно.
- [ ] Пользователь может выбрать нескольких специалистов одновременно.
- [ ] При добавлении шага создаются отдельные действия в `sequenceActions`.
- [ ] Проект успешно собирается (`npm run build`).
- [ ] PHPUnit-тесты проходят без ошибок (`php artisan test`).
