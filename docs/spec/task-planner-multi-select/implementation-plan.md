# Implementation Plan: Мультивыбор зданий и специалистов в Task Planner

## Этапы разработки

### Этап 1: Обновление состояния и реактивных функций в `Tasks.vue`
1. Замена `selectedBuilding`, `selectedFriendBuilding` на `selectedBuildings` (массив целевых объектов).
2. Замена `selectedSpecialist` на `selectedSpecialists` (массив специалистов).
3. Добавление переключателя зон `buildingTargetScope` (`self` / `friend`) и вынос табов из модального окна.
4. Сохранение значения задержки `stepDelay` после выполнения `addStepToSequence`.

### Этап 2: Модификация модальных окон
1. **Модальное окно зданий**:
   - Формирование списка зданий выбранного острова (`self` или `friend`).
   - Мультиселект с чекбоксами/подсветкой выбранных карточек.
   - Кнопка "Выбрать все visible" / "Снять выбор".
   - Фильтрация по категориям и поисковой строке.
   - Закрытие по крестику (❌), клику на оверлей и клавише ESC.
2. **Модальное окно специалистов**:
   - Мультиселект с чекбоксами/подсветкой.
   - Поиск и фильтрация.
   - Кнопки массового выделения.

### Этап 3: Сортировка задач и двухъязычный маппинг ошибок
1. Сортировка `ScheduledTaskController@index` и `groupedTasks` по `id desc` (новые задачи вверху).
2. Вынос ошибок TSO сервера в `lang/en/ui.php` (default) и `lang/ru/ui.php`.
3. Декодирование кодов ошибок в `GameErrorResolver` и `getActionStepError` в Vue.

### Этап 4: Разворачивание множественного выбора в действия (`addStepToSequence`)
1. Валидация наличия хотя бы одной цели при добавлении шага.
2. Цикл итерации по выбранным зданиям/специалистам с генерацией отдельного действия для каждого объекта в `sequenceActions`.
3. Очистка временных массивов выбора после добавления шагов с сохранением `stepDelay`.

### Этап 5: Сборка и верификация
1. Экспорт локализаций: `php artisan tso:lang:export-frontend`.
2. Компиляция фронтенда через `npm run build`.
3. Запуск интеграционных PHPUnit-тестов `php artisan test`.

- [x] Модалка закрывается по крестику (❌), оверлею и ESC.
- [x] Время задержки (`stepDelay`) сохраняется при добавлении действий.
- [x] Новые задачи отображаются вверху списка (`id desc`).
- [x] Ошибки сервера выводятся человекочитаемым текстом на языке UI (English / Русский).
- [x] Проект успешно собирается (`npm run build`).
- [x] PHPUnit-тесты проходят без ошибок (`php artisan test`).
