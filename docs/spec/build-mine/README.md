# build-mine: постройка и апгрейд шахт на залежах

Спецификация двух новых типов задач планировщика:

| Тип задачи | Значение | Что делает |
| --- | --- | --- |
| `build_mine` | `TaskType::BuildMine` | строит шахту на разведанной залежи (игровая команда `50`) |
| `upgrade_mine` | `TaskType::UpgradeMine` | улучшает уже стоящую шахту (игровая команда `60`) |

## Порядок чтения (обязательный)

Читай документы строго по порядку. Не начинай писать код, пока не прочитаны
первые пять файлов.

1. `README.md` — этот файл: глоссарий, границы задачи.
2. `requirements.md` — что именно должно работать (FR), инварианты (INV), критерии приёмки (AC).
3. `data-sources.md` — доказательная база: откуда взяты команды, номера зданий, поля залежей.
4. `decisions.md` — ADR: почему сделано именно так. Отклонение от ADR запрещено без правки ADR.
5. `design.md` — архитектура: классы, интерфейсы, сигнатуры, обоснование по SOLID.
6. `implementation-plan.md` — пошаговый план с полными путями файлов и готовыми фрагментами кода.
7. `verification.md` — тесты, ручная проверка, гейты качества.
8. `pitfalls.md` — типовые ошибки. Прочитай перед первым коммитом и ещё раз перед финальной проверкой.

## Глоссарий

| Термин | Значение |
| --- | --- |
| **Грид (grid)** | целочисленный индекс клетки игровой карты. Не идентификатор объекта: на одном гриде может стоять залежь, здание или ничего |
| **Залежь (deposit)** | месторождение руды на карте. Появляется после разведки геологом. В зоне описывается объектом `dDepositVO` |
| **Руда (ore)** | тип залежи: `BronzeOre`, `IronOre`, `Coal`, `GoldOre`, `TitaniumOre`, `Salpeter` |
| **Шахта (mine)** | здание, которое можно поставить только на залежь своей руды: `BronzeMine`, `IronMine`, `CoalMine`, `GoldMine`, `TitaniumMine`, `SalpeterMine` |
| **Номер здания (buildingNumber)** | целое число, которым игровой сервер идентифицирует тип постройки в команде `50`. Например `50` = `IronMine` |
| **Очередь стройки (build queue)** | ограниченный список одновременно возводимых/улучшаемых зданий. Если свободных слотов нет, команда бессмысленна |
| **Снапшот зоны (zone snapshot)** | результат разбора свежего ответа игрового сервера на `GET_ZONE` (`1001`) |

## Что входит в объём

- Постройка базовых шахт шести типов на разведанных залежах.
- Апгрейд этих шахт до заданного уровня (максимум `7`).
- Валидация цели до отправки команды: тип руды, занятость грида, свободные слоты очереди.
- Извлечение залежей и очереди стройки в снапшот зоны (доработка Python-парсера).
- Два read-only API-эндпоинта для наполнения UI.
- Пункты в модалке выбора действия планировщика задач.

## Что НЕ входит в объём (Non-goals)

1. **Epic / Arctic / Endless шахты** (`EpicIronMine`, `ArcticGoldMine`, `BronzeMineEndless`).
   У них отдельные ограничения по количеству и механика `depletedMineExtension`.
2. **Постройка из баффа** (`SET_BUILDING_BY_BUFF`, требует `SetBuildingVO` с id баффа).
3. **Любые другие здания, кроме шахт.** Каталог намеренно ограничен шестью записями;
   расширение — отдельная задача с отдельной проверкой номеров.
4. **Перемещение и снос шахт.** Шахты имеют `movable="false"`.
5. **Мгновенная достройка за самоцветы** (`InstantBuildCosts`).
6. **Автоматический подбор залежи** («построй где-нибудь»). Задача всегда адресует конкретный грид.

## Ключевой принцип безопасности

Ошибка в номере здания или гриде приводит к безвозвратной трате ресурсов игрока и
занятому слоту очереди стройки. Поэтому действует правило: **при любом сомнении
команда не отправляется**. Отказ (skip) — всегда корректный исход; отправка команды
«на всякий случай» — нет.
