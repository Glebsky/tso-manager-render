## Ручные сценарии

### S-1. Сценарий безопасности — выполняется ПЕРВЫМ

Пока этот сценарий не пройден, никакие проверки успешного пути на живом аккаунте
не запускаются.

1. Выбрать в зоне обычное производственное здание (например `Woodcutter`).
2. Создать через API задачу с `mode = collectible` на его `grid`.
3. Запустить вручную через «Run now».

Ожидаемо:

- задача завершается ошибкой `building_not_clickable`;
- здание на месте, производство не затронуто;
- в логах видна причина отказа и **ни одного** исходящего AMF-вызова после загрузки зоны.

Проверка отсутствия трафика — обязательная часть сценария, а не желательная.

### S-2. Коллекция, успешный путь

1. Найти `CollectibleHerbsBuilding` и запомнить его `grid` и текущие запасы ресурса.
2. Задача с `mode = auto`, запуск вручную.
3. Повторить запуск ещё раз.

Ожидаемо: первый запуск — ресурс вырос, в логах `reason = allowlist_match`;
второй — скип `not_found`, задача не падает (INV-6).

### S-3. Праздничное здание, успешный путь

1. В зоне есть `FlyingHouse` или Christmas Tree с готовым подарком
   (в игре виден анимированный иконка-маркер над зданием).
2. Задача с `mode = auto` на его `grid`, запуск вручную.
3. Сохранить сырой дамп запроса и ответа AMF.
4. Повторить запуск сразу же.

Ожидаемо: подарок получен, здание НА МЕСТЕ, второй запуск — no-op или `551` без
падения задачи. Дамп из п. 3 закрывает вопрос Q-3.

### S-4. Неизвестное здание в режиме `auto`

Выбрать здание, которое не подходит ни под один шаблон allow-list.

Ожидаемо: в логах `reason = auto_fallback_safe`, отправлена команда квест-триггера,
а не команда сноса; здание на месте (AC-5).

### S-5. Серия из мультивыбора

Выбрать 5 зданий в существующей модалке, собрать серию, запустить.

Ожидаемо: 5 шагов, частичный успех помечен `PARTIAL:`, сводка по шагам читаемая.
