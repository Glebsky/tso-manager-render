# SDD: Миграция приложения на PHP 8.5

- **Статус:** Draft / Planning
- **Версия пакета:** 1.0
- **Проект:** Laravel 12 / Vue 3 (TSO Manager)
- **Компонент:** Runtime & Infrastructure (`Dockerfile`, `composer.json`, `docs/spec/constitution.md`, `AGENTS.md`)

## Назначение

Настоящая спецификация описывает комплексный процесс обновления среды исполнения (PHP Runtime) приложения **TSO Manager** с PHP 8.4 до **PHP 8.5**. 

Обновление охватывает:
1. Обновление базовых Docker-образов (`php:8.5-fpm-alpine`) и зависимостей Composer.
2. Проверку и обеспечение полной совместимости всех используемых сторонних пакетов (Laravel Framework 12, Larastan 3.x, PHPStan 2.x, PHPUnit 10/11, Pint).
3. Устранение возможных устаревших возможностей (deprecations) и обратных несовместимостей PHP 8.5.
4. Внедрение новых возможностей и эргономических улучшений PHP 8.5 в соответствии с `constitution.md`.
5. Обновление управляющих спецификаций и стандартов проекта (`constitution.md`, `AGENTS.md`).

## Документы спецификации

1. [Requirements](requirements.md) — функциональные и нефункциональные требования, требования безопасности, критерии приемки и Definition of Done.
2. [Design](design.md) — архитектура среды исполнения, конфигурация Docker и Composer, матрица совместимости зависимостей и стратегия адаптации синтаксиса PHP 8.5.
3. [Implementation Plan](implementation-plan.md) — декомпозиция на пакеты работ (Work Packages), порядок проведения миграции, оценка рисков и стратегия отката.
4. [Verification](verification.md) — матрица проверок, автоматические гейты качества и процедуры валидации контейнеров.
