## Главное открытие этого раунда

В v1.0 тип 7 (Combat 3 Units, здание `Barracks3`) был помечен `unsupported:needs_tier_data`, потому что источник данных не был найден.

**Источник найден.** Это `settings/game_units.xml` из архива — маленький файл на 14 КБ, который в v1.0 был отмечен как «не нужен». Это была ошибка классификации: именно этот файл и есть тот `cMilitaryUnitData`, который клиент читает через `GetAllUnitDataByTier(true, tier)`.

В нём есть всё, чего не хватало: атрибут `Tier`, атрибут `group`, флаг `IsProducible`, время производства, стоимость мгновенного завершения и стоимость в товарах.

Итог: **7 производимых юнитов типа 7**, все Tier 3, три группы. Подробности — `combat3-units.md`.

**Больше ни одного типа со статусом `unsupported` не осталось**, кроме типа 3, у которого вообще нет здания-производителя. Инвариант INV-6 теперь требует ненулевого числа рецептов для каждого из 69 типов.

Это упрощает тест `CatalogCoverageTest`, но ветку с `unsupported:` следует оставить в коде на будущее — игра патчится, новые типы появляются.
