## 3. Инварианты (нарушение = дефект)

1. **INV-1. Один аккаунт — одна игровая сессия.** Любые два процесса, работающие с одним `account_id`, обязаны переиспользовать одну и ту же запись сессии из `Cache`. Создание второй сессии — источник ошибки `1012`.
2. **INV-2. Полный логин — только при мёртвой сессии.** `login()` не должен вызываться «на всякий случай».
3. **INV-3. Семантика вызовов авторизации:**
   - `ensureAuthenticated($account)` — «сделай так, чтобы можно было работать» (проверит и при необходимости войдёт). **Это единственный метод, который вызывают прикладные сервисы.**
   - `login($account)` — «войти, если этого уже не сделал другой процесс» (идемпотентен в пределах TTL флага).
   - `resetSession($account)` + `login($account)` — «принудительный полный вход». Только так, и только после реальной ошибки игрового сервера (`1005`/`1012`) или смены пароля.
4. **INV-4. Транспортная ошибка ≠ протухшая сессия.** Таймаут, `HTTP 500/502`, сетевой сбой не должны приводить к релогину. Релогин допускается только по признакам, перечисленным в Ф4.
5. **INV-5. Никаких секретов на диск.** Ни `dsoAuthToken`, ни HTML страницы `play` не сохраняются в `storage/`. Логи проходят через `App\Support\Security\CredentialRedactor`.
6. **INV-6. Обратная совместимость по данным.** Схема БД не меняется; существующие аккаунты продолжают работать без ручных действий.

### 3.1. Соответствие принципам

- **SOLID / SRP:** `TsoAuthService` отвечает за веб-сессию (получить/проверить/сбросить). `HttpTsoClient` — за игровой транспорт (endpoint, `DSId`, AMF). Ф4 не добавляет в транспорт логику логина: транспорт только **сообщает** о протухании типизированным исключением, решение принимает вызывающий.
- **SOLID / DIP:** прикладной код продолжает зависеть от `TsoClientInterface`; новые методы добавляются в `TsoAuthService` (уже singleton в `TsoServiceProvider`), интерфейс транспорта не расширяется.
- **SOLID / OCP:** порядок ветвей логина (Ф6) выбирается данными (значение в кэше), а не новыми `if` в шести местах.
- **DRY:** проверка «авторизован ли» была скопирована в 6 местах — сводится к одному `ensureAuthenticated()` (Ф7); дублирующиеся заголовки браузера сводятся к константе (Ф3).
- **KISS:** никаких новых абстракций, событий, очередей и фича-флагов. Один новый класс-исключение и три новых метода.
